# 킹고 헬스케어 — 실습용 가상 데이터 (A. 회사 실무)

**이 데이터는 실습을 위해 만든 가상 사례입니다. 실제 회사·인물·시장 수치가 아닙니다.**

| 파일 | 내용 |
|---|---|
| `meeting_minutes.md` | 1차 임원 회의록 — 마케팅 부사장(온라인 집중)과 재무 상무(약국 우선)의 의견 대립, CEO 요청 |
| `consumer_survey.csv` | 베트남 소비자 설문 결과 (선호도, 선호 효능, 지불 가능 구독료, 선호 구매 채널) |
| `initial_budget.csv` | 1차년도 초기 투자 예산 15억 원과 항목별 배분, 제약 조건 |

상황: 한국 건강기능식품 회사 '킹고 헬스케어'가 베트남 진출을 준비 중이다. 총예산 15억 원 중 고정비 8억 원을 빼면 마케팅·유통에 쓸 수 있는 돈은 7억 원이다. 온라인(틱톡샵·쇼피)에 집중하면 대형 약국 체인 입점 보증금(최소 3억 원)을 낼 수 없고, 약국에 집중하면 앱 초기 트래픽 예산이 모자란다. CEO는 데이터 근거로 절충안 2가지를 요청했다.

수업용 요청 예:

```
samples/kingo-healthcare 데이터로 킹고 헬스케어 베트남 진출 채널 전략 보고서를 경영진 보고용으로 빠르게 만들어줘
```
