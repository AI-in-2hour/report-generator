# 킹고 헬스케어 — 실습용 가상 데이터

**이 데이터는 실습을 위해 만든 가상 회사 데이터입니다. 실제 회사·시장 수치가 아닙니다.**

| 파일 | 내용 |
|---|---|
| `consumer_survey.csv` | 베트남 소비자 설문 결과 (선호도, 선호 효능, 지불 가능 구독료, 선호 구매 채널) |
| `initial_budget.csv` | 베트남 진출 초기 투자 예산 15억 원과 항목별 배분, 제약 조건 |

상황: 한국 건강기능식품 회사 '킹고 헬스케어'가 베트남 진출을 준비 중이다. 이사회가 승인한 예산은 15억 원이며 추가 증액이 불가능하다. 마케팅·유통에 쓸 수 있는 돈은 7억 원인데, 온라인(틱톡샵·쇼피)에 집중하면 약국 체인 입점 보증금(최소 3억 원)을 낼 수 없고, 약국에 집중하면 앱 초기 트래픽 예산이 모자란다.

수업용 요청 예:

```
samples/kingo-healthcare 데이터로 킹고 헬스케어 베트남 진출 전략 보고서를 경영진 보고용으로 빠르게 만들어줘
```
