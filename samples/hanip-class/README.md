# 한입클래스 — 실습용 가상 데이터

**이 데이터는 실습을 위해 만든 가상 사례입니다. 실제 회사·서비스·시장 수치가 아닙니다.**

| 파일 | 내용 |
|---|---|
| `idea_memo.md` | 1인 창업 아이디어 메모 (고객, 문제, 해결, 가격, 확인할 것) |
| `survey.csv` | 직장인 200명 설문 결과 (점심시간 활용, 이용 의향, 지불 의향, 주제) |
| `competitors.csv` | 경쟁 서비스 4개 비교 (가상) |
| `plan_6months.csv` | 6개월 런칭 계획 (구독자, 매출, 비용, 손익) |

상황: 직장인이 점심시간 15분 동안 듣는 짧은 수업 구독 서비스 '한입클래스'를 창업자 혼자, AI 도구로 만들려고 한다. 가격은 월 7,900원, 6개월 차 목표는 구독자 900명과 월 흑자다.

수업용 요청 예:

```
samples/hanip-class 데이터로 한입클래스 6개월 런칭 계획 검토 보고서를 투자자 보고용으로 빠르게 만들어줘
```
